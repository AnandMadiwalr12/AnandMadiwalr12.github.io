## Before publishing

The Nitara Connector project document is linked from the Mobile Application project card. Confirm that GormalOne/Nitara has authorized public sharing and remove all confidential, customer, production, or personal data before enabling GitHub Pages.

## Publish with GitHub Pages

1. Create a public GitHub repository named `AnandMadiwalr12.github.io`.
2. Upload these files to the repository's main branch.
3. In GitHub, open **Settings > Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Your resume-ready URL will be:

   `https://AnandMadiwalr12.github.io`

## Run locally

Open `index.html` in a browser. No build step or package installation is required.
